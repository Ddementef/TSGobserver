# Использование готового exe-файла

Вы можете просто скачайть `TSGobserver.exe` и запустить его. Дополнительная установка не требуется. Если вы хотите изучить код и ииспользовать под свои нужды - читайте файл далее. Если вы хотите просто скачать и запустить - дальнейшие пункты для Вас не несут актуальности.

### Автозапуск Windows

Программа имеет встроенную функцию автоматического добавления в автозапуск Windows.

#### Автоматическое предложение

При запуске программы (если она еще не добавлена в автозапуск) появится диалоговое окно с рекомендацией добавить приложение в автозапуск. Вы можете:
- **Да** - программа будет автоматически добавлена в автозапуск
- **Нет** - программа продолжит работу, диалог больше не появится

#### Ручное управление автозапуском

В главном окне программы есть кнопка управления автозапуском:
- **Статус автозапуска** - отображается текущее состояние (Включен/Выключен)
- **Кнопка переключения** - позволяет включить или выключить автозапуск в любой момент

**Примечание**: Программа автоматически создает необходимые файлы в папке автозапуска Windows (`shell:startup`).

### Автоматическое обновление

Программа автоматически проверяет наличие новых версий при каждом запуске.

#### Как это работает

- При запуске приложения (с небольшой задержкой) выполняется проверка последнего релиза на GitHub
- Если найдена более новая версия, появляется диалоговое окно "Вышло новое обновление"
- Вы можете:
  - **Да** - откроется страница последнего релиза на GitHub для скачивания новой версии
  - **Нет** - диалог закроется, приложение продолжит работу

**Примечание**: Проверка обновлений выполняется в фоновом режиме и не влияет на работу приложения. Если проверка по какой-то причине не удалась (нет интернета, проблемы с GitHub API и т.д.), приложение продолжит работать в обычном режиме.

## Принцип работы

Программа автоматически начнет мониторинг процессов при запуске. Когда будут запущены оба процесса (`TSGLauncherA3AC.exe` и `arma3_x64.exe`), программа будет автоматически завершать отслеживаемые приложения.

Программа работает следующим образом:

1. **Мониторинг целевых процессов**: Каждые 5 секунд программа проверяет, запущены ли одновременно:
   - `TSGLauncherA3AC.exe` (лаунчер TSG)
   - `arma3_x64.exe` (Arma 3)

2. **Завершение приложений**: Если оба целевых процесса запущены, программа автоматически завершает следующие приложения:
   - Telegram
   - Discord
   - WhatsApp
   - EA Desktop
   - Zoom
   - Skype
   - GameCenter
   - FACEIT
   - Ubisoft (Uplay / Ubisoft Connect)
   - Battle.net
   - VK Play
   - VK
   - Facebook
   - Одноклассники
   - Viber
   - GOG GALAXY
   - Microsoft Teams
   - Slack
   - OMEN Gaming Hub

3. **Интерфейс**: Программа имеет графический интерфейс, который показывает:
   - Текущий статус мониторинга
   - Список обнаруженных приложений, которые будут закрыты
   - Кнопки для запуска/остановки мониторинга

**Важно**: Приложения закрываются только когда оба целевых процесса (`TSGLauncherA3AC.exe` и `arma3_x64.exe`) запущены одновременно. Если хотя бы один из них не запущен, приложения останутся работать.

## Запуск из исходного кода

Если вы хотите запустить программу из исходного кода:

### Требования

- Python 3.7 или выше
- pip (менеджер пакетов Python)

### Установка зависимостей

1. Убедитесь, что Python установлен:

   python --version


2. Установите необходимые библиотеки из файла `requirements.txt`:

   pip install -r requirements.txt (используйте свой полный путь для requirements.txt)


    Это установит:
    - `psutil` - для работы с процессами
    - `pillow` - для обработки иконки приложения
    - `requests` - для проверки обновлений через GitHub API
    **Примечание**: `Pillow` указан в requirements.txt, но не является обязательным для работы программы. Он используется только для правильной конвертации встроенной иконки из PNG в ICO формат при запуске из исходного кода. Программа будет работать и без него, но иконка окна будет сохранена как PNG вместо ICO. Для exe-файла Pillow не нужен, так как используется внешний файл иконки.

### Запуск программы

После установки зависимостей запустите программу:

```bash
python TSGobserver.py
```

## Сборка exe-файла

Для создания исполняемого файла рекомендуется использовать **auto-py-to-exe** - графический интерфейс для PyInstaller.

### Установка auto-py-to-exe

Установите auto-py-to-exe через pip:

```bash
pip install auto-py-to-exe
```

### Запуск auto-py-to-exe

Запустите программу:

```bash
auto-py-to-exe
```

Откроется графическое окно с настройками сборки.

### Настройки сборки

В окне auto-py-to-exe настройте следующие параметры:

1. **Script Location** (Расположение скрипта):
   - Нажмите "Browse" и выберите файл `TSGobserver.py`

2. **Onefile** (Один файл):
   - Выберите **"One File"** (один файл)

3. **Console Window** (Окно консоли):
   - Выберите **"Window Based (hide the console)"** (скрыть консоль)

4. **Icon** (Иконка):
   - Нажмите "Browse" и выберите файл `SG.ico`
   - **Примечание**: Иконка должна быть в формате .ico

5. **Additional Files** (Дополнительные файлы):
   - Оставьте пустым (иконка встроена в код)

6. **Output Directory** (Папка вывода):
   - Выберите папку, куда будет сохранен готовый .exe файл

7. **Нажмите "CONVERT .PY TO .EXE"** для начала сборки

### Альтернативный способ: PyInstaller (командная строка)

Если вы предпочитаете использовать PyInstaller напрямую:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name TSGobserver --icon=SG.ico TSGobserver.py
```

Параметры:
- `--onefile` - создает один исполняемый файл
- `--windowed` - скрывает консольное окно (для GUI приложений)
- `--name TSGobserver` - имя выходного файла
- `--icon=SG.ico` - иконка приложения
- `TSGobserver.py` - исходный файл программы

После завершения сборки исполняемый файл будет находиться в папке `dist/TSGobserver.exe`.

### Примечания

- Иконка `SG.ico` должна находиться в той же папке, что и `TSGobserver.py`
- Размер готового exe-файла будет около 15-20 МБ (зависит от версий библиотек)
- Антивирусы могут помечать exe-файлы как подозрительные. Это нормально для программ, собранных через PyInstaller
- При использовании auto-py-to-exe все настройки сохраняются визуально, что упрощает процесс сборки
